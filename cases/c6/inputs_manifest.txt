IMPORT ORDER IN RAS MAPPER
  1. terrain_2d.tif                    -> New Terrain
  2. landcover_2d.tif + manning_n_2d.csv -> Land Cover / Manning's n
  3. for_ras/domain_2d.shp             -> 2D Flow Area perimeter
  4. for_ras/breaklines.shp            -> Breaklines  (DIVIDE CREST FIRST)
  5. for_ras/refinement.shp            -> Refinement Regions
  6. Generate mesh, then RUN C6-2d-qa.py BEFORE COMPUTING
  7. for_ras/bc_lines.shp              -> BC lines

THE CHECK THAT MATTERS
  A 3.3 ft divide survives a 15 m mesh only if cell faces lie ON the crest.
  If the mesh does not honour the divide breakline, water crosses at the
  averaged elevation and the model reports a spill that is an artifact.
  C6-2d-qa.py checks this against the LiDAR crest. Do not skip it.
